# 한국 등급분류(게임물관리위원회) 준비

국내에 정식으로 팔려면 게임물관리위원회(GRAC) 등급분류가 필요하다 — Steam 은 아직 한국 자체등급분류 사업자가 아니어서(2021~2025 보도) 개발사가 직접 받는다.
신청·결제·서명은 오너(신청자 본인 인증)가 한다. 이 문서는 그때 쓸 답과 준비물을 미리 모아 둔다(2026-11-05 Claude 조사 — 신청 전에 grac.or.kr 에서 다시 확인).

## 비용·기간 (2025-10 보도 기준)

- PC·콘솔 게임 심사료 **324만원(부가세 별도, 356.4만원)** — 기본료 36만원에 이용 형태·장르 계수·한글화 여부를 곱한다. 인디 감면은 찾지 못했다
  (오픈마켓 300MB 미만 게임의 30% 감면은 PC 게임과 다르다).
- 심사 10~15일. 반려돼도 환불 없음, 재심사는 75%. 플랫폼마다 다시 내면 다시 낸다.
- **먼저 "모의 등급분류"** 로 필요한 서류·수수료를 미리 본다(grac.or.kr).
- 받지 않은 해외 게임에 위원회는 계도 수준이었다(2020 보도). 국내 개발자는 받는 쪽이 안전하다. 받지 않으려면 Steam 에서 한국 판매를 막아야 한다(주 언어가 한국어라 권하지 않는다).

## 신청 절차

1. grac.or.kr 회원가입·로그인(개인 또는 사업자) → 상단 [등급분류신청].
2. 신청서 + 게임내용설명서(아래 초안) + 자기기술서(아래 표) + **가장 극단적인 장면의 영상**(폭력·공포 등 — 아래 "영상").
3. 수수료 결제 → 심사 → 등급분류증명서. 받은 등급은 Steam 스토어 페이지에도 적는다(README 7절, Content Survey 와 별개).

## 게임내용설명서 초안

```text
제목: TheSword (더 소드)                  플랫폼: PC (Windows 64-bit, Steam)
장르: 퍼즐 롤플레잉 — 100층 탑을 오르며 문·열쇠·몬스터 순서를 짜는 완전 정보 퍼즐(魔塔 장르)
이용 형태: 1인 오프라인. 다른 이용자와의 대화·거래 없음. Steam 업적·순위표(점수)만 온라인.
결제: 유료 판매 한 번. 게임 안 구매·무작위 보상(뽑기)·확률형 아이템 없음.
언어: 한국어·영어·일본어·간체 중국어 (원어 한국어)
내용: 주인공 데미안이 영혼을 거는 계약으로 얻은 마검과 함께 탑을 오른다. 몬스터와 부딪히면 자동 전투가 열리고,
      마검의 눈이 "이 싸움에서 잃을 체력" 을 미리 보여 준다. 그림은 픽셀 아트(인물 일러스트는 2D 그림).
```

## 자기기술서 — 항목별 사실 (이 게임에 있는 그대로)

| 항목 | 있나 | 내용 |
|---|---|---|
| 폭력성 | 있음(판타지) | 마물·언데드(슬라임·늑대·까마귀·고블린 창병·해골 검사·얼어붙은 기사·방패병 같은 것)와의 자동 전투. 칼 휘두름·맞는 효과·화면 흔들림. 몬스터는 흰 빛·보라 넋으로 사라진다. 플레이어가 쓰러질 때 **짙은 빨간 입자**가 잠깐 터진다. 절단·시체·고문 없음 |
| 공포 | 약함 | 무덤·검은 태양 같은 어두운 판타지 분위기, 보스 등장 때 화면 흔들림. 갑자기 놀래키는 장면 없음 |
| 언어 | 약함 | 심한 욕설 없음. 가벼운 표현("젠장" 한 번), 마검의 놀림("허접", "바보"). 대본에 "피" 가 두 번(잃을 체력의 비유) |
| 선정성 | 없음 | 노출·성적 표현 없음 |
| 술·담배·마약 | 없음 | |
| 범죄·모방 위험 | 없음 | |
| 사행성 | 없음 | 무작위 보상·도박·확률형 아이템 없음(모든 정보가 보이는 퍼즐) |

예상 등급은 판타지 폭력과 빨간 입자 때문에 **12세 이용가** 쪽으로 본다 — 추정일 뿐이니 모의 등급분류로 확인한다.

## 영상

"가장 극단적인 장면" 을 담는다 — 100층 보스전, 플레이어가 쓰러지는 장면(빨간 입자), 20·40층 보스 등장(화면 흔들림), 3층 계약 장면.
- 에디터에서 `PlaythroughRecorder`(CLAUDE.md "완주 녹화") 로 뽑거나, 스토어 미디어를 찍던 체크포인트(`Build/Store/`, 이 PC 에만 있다)를 불러 찍는다.
- 쓰러지는 장면은 봇이 거의 안 지므로 사람이 지는 싸움을 일부러 한 번 한다("그래도 싸울까" 에서 예).
