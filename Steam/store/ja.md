# 스토어 문구 — 일본어 (japanese)

붙일 곳: 스토어 페이지 관리 → **설명** 탭, 언어 = 日本語. 규칙·태그·콘텐츠 설문 메모는 `ko.md` 와 같다.
게임 안 이름·용어는 ScriptData 와 `Tools/story/story_jp.json` 에 맞췄다(会心, 予想ダメージ, モンスター図鑑, ワープ石の指輪, 我輩…).
"마탑" 은 일본에서 덜 알려져 "魔塔系" 로 적고 뜻을 풀어 썼다. 원어민 검수 전 초안이다.

## 짧은 설명

```text
運の入り込む余地がない、魔塔系パズルRPG。しゃべる魔剣エゴソードの片目は、戦うたびに失う体力を正確に見通す。扉も鍵もポーションも、すべて値段のついた選択だ。100階の道筋を組み立て、剣を満腹にし、最後にその値段を誰が払うかを選べ。
```

## 게임 정보 (About This Game)

```text
[h2]運が入り込む余地のない塔[/h2]
モンスターは敵ではなく値札。体力は命ではなく予算。この塔にランダムは一切ない。頭上に浮かぶ数字が、その戦いで失う体力そのものだ。決めるのは、何をどの順番で払うかだけ。

[h2]物語[/h2]
傭兵ダミアンは、ガブ村に落ちてきた塔を調べに来た。空から落ち、大地に逆さまに突き刺さった黒い塔だ。忘れられた森で、彼は喋る魔剣エゴソードと契約する。魂と命を賭けて。
魔剣の片目は、あらゆる戦いの値段を見せてくれる。ただひとつ、契約者自身の値段だけを隠したまま。

[h2]特徴[/h2]
[list]
[*][b]すべてのモンスターに正確なダメージ予測[/b]：契約の後、マップ上のすべてのモンスターの頭上に「次に戦うと失う体力」が浮かぶ。実際の戦闘を先に回して出した値なので、スキルを使わなければ少しもずれない。勝てない相手には赤いX、倒すとレベルが上がる相手には★。
[*][b]8種の特性[/b]：野獣・魔法・守護・不死・剣士・巨体・暗殺・鎧。会心を受けるまですべての攻撃をかわす暗殺、まず殻を割らねばならない鎧、五回殴られるたびに吠えてやり返す巨体……章ごとに通じる手が違う。
[*][b]読めるゲージ式バトル[/b]：攻撃・防御ゲージがたまると自動で戦う。会心は確率ではなく決まった回数ごとに出て、数えた回数は戦いが終わっても続く。誰を先に斬るかで値段が変わる。強打・鉄壁・吸血の3つのスキルを戦いごとに一度ずつ差し込めば、予測より安く勝てる。
[*][b]100階、5つの章[/b]：苔むした地下墓所、崩れた水路、灰色の溶鉱炉、凍てついた深層、玉座の亀裂。緑・黄・赤の扉と鍵、金庫と予備の鍵、永続的に強くなるルーン、どちらか一つしか取れない報酬、そして20階ごとの章ボス。20階のボスを倒せば、行ったことのある階へ飛べるワープ石の指輪が手に入る。
[*][b]溢れた分は捨てられる[/b]：体力には上限がある。ポーションをいつ飲むかまで計算のうちだ。
[*][b]モンスター図鑑[/b]：その階の種ごとに能力値、残り数、次の戦いの値段、被弾回数、そして「攻撃 +k → 被弾 1回減」。
[*][b]魔剣の飢えと3つの結末[/b]：魔剣はダミアンが斬った魔物の魔力を食らう。最後の選択は2つ、結末は3つ。真の結末を見られるのは、剣を満腹にした者だけだ。
[*][b]階ごとのチェックポイント[/b]：階に入るたびに自動で保存される。倒れるとその階の入口に戻り、メニューからは直近10階のどこからでもやり直せる。
[/list]
買い切り。DLCもゲーム内課金もありません。
```
