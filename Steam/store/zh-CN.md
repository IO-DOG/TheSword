# 스토어 문구 — 간체 중국어 (schinese)

붙일 곳: 스토어 페이지 관리 → **설명** 탭, 언어 = 简体中文. 규칙·태그·콘텐츠 설문 메모·줄마다의 근거는 `ko.md` 와 같다.
魔塔 장르 리뷰의 84% 가 간체 중국어다(MASTER_PLAN §1). 그래서 이 페이지는 魔塔 팬의 말로 썼다.
2026-11-03 갱신: `main` `970333f3`(Wave 3 포함) 빌드 기준. 한국어 판과 같은 사실을 말하되, 이 장르 사람들이 평가하는 순서로 묶었다 —
먼저 장르의 기본기(显伤·临界·楼传), 다음에 다른 점, 그다음에 "통과 뒤의 천장"(通关只是及格线: 账簿·祭坛·排行榜·塔之法则).

| 魔塔 말 | 뜻 | 이 게임에서 |
|---|---|---|
| 显伤 | 몬스터 위에 받을 피해를 띄우는 것 | 맵 위 예측 숫자 (계약 뒤). 게임 안 이름은 "战斗预测" 라서 본문에 한 번 풀어 썼다 |
| 临界 | 공격을 몇 올리면 맞는 횟수가 주는 문턱 | 도감의 "攻击 +k → 少挨一次" (ScriptData 265)와 룬 툴팁 "攻击 +1 → 怪物 -a→-b" |
| 楼传 | 층 이동 도구 | 20층 보스가 주는 传送石戒指 |
| 怪物手册 | 고전 魔塔의 몬스터 정보 도구 | 게임 안 이름은 "怪物图鉴" — 본문에 둘을 이어 썼다 |

- 게임 안 이름·용어는 ScriptData 와 `Tools/story/story_cn.json`, `Tools/ui_text_parts/*.py` 에 맞췄다(自我之剑, 达米安, 加布村, 遗忘之森, 暴击, 怪物图鉴, 魔剑的账簿, 预言·付出·基准, 祭坛, 塔之法则, 普通, 检查点…).
- 전통 魔塔 과 다른 점(체력 상한·넘침, 게이지 전투, 층 입구 저장)을 숨기지 않았다. 저장은 "어디서나" 가 아니라 **층 입구**다 —
  세이브 불만이 이 장르의 나쁜 리뷰에 2.2배 많이 나온다(§1). 기대를 먼저 맞춰 둔다. 전투를 건너뛸 수 없다는 불만이 3D 魔塔의 몰락 원인이었으므로(재미 검증 보고서) 배속·跳过도 앞쪽에 둔다.
- 중국어 편집자(W0) 검수 전 초안이다. "首领"(boss)은 트레일러 자막과 맞췄다 — 게임 안 중국어 글에는 boss 를 가리키는 말이 따로 없고, 장르에서는 BOSS 도 흔하다. 편집자가 정한다.
- 본문의 "Steam排行榜"·"20个Steam成就" 는 Steamworks 에 그 순위표·업적을 만들어 Publish 한 뒤에만 붙인다(README 5절). 시스템 요구 사항 표에는
  处理器·内存 행이 없다 — 측정값이 나오면 오케스트레이터가 채운다(`ko.md` 머리말). 본문 맨 끝 줄은 글꼴 Silver 의 CC BY 4.0 표기다.

## 짧은 설명

```text
零随机、全凭计算的魔塔RPG。会说话的魔剑睁着独眼，替每只怪标出精确显伤，怪物图鉴连临界都帮你算好，战斗还能加速、跳过。每扇门、每把钥匙、每瓶药水，都是有价码的选择。规划100层路线，冲三星、冲排行榜，最后决定由谁来付这笔账。
```

## 게임 정보 (About This Game)

```text
[h2]一座不靠运气的魔塔[/h2]
怪物不是敌人，是价码；血量不是命，是预算。塔里没有任何随机：怪物头顶的数字，就是这一战你要掉的血。你要决定的，只是付哪几笔、按什么顺序付。

[h2]显伤、临界、楼传，一样不少[/h2]
[list]
[*][b]显伤[/b]（游戏内叫“战斗预测”）：与魔剑立约之后，地图上每只怪物头顶都会显示“下一战会损失多少生命”。这个数字是把真实的战斗提前跑一遍算出来的，不用技能的话分毫不差。打不过的标红色X，打完能升级的标★。
[*][b]临界[/b]：打开怪物图鉴（就是魔塔老玩家熟悉的“怪物手册”），本层每种怪的攻防血、剩余数量、下一战的价码、要挨几下一目了然，临界直接写明——“攻击 +k → 少挨一次”。把鼠标移到攻击/防御符文上，还会预告捡起它之后，哪些怪的显伤会从多少降到多少。
[*][b]楼传[/b]：击败第20层首领后获得传送石戒指，去过的楼层都能直接传送回去。
[/list]

[h2]和传统魔塔不一样的地方[/h2]
[list]
[*][b]生命有上限[/b]：药水（就是魔塔里的血瓶）回复超出上限的部分会白白浪费，什么时候喝，本身就是一道计算题。
[*][b]看得懂的槽式战斗[/b]：攻击槽、防御槽满了就自动出手。暴击不看概率，而是每隔固定次数必出，次数会带到下一场战斗——先打谁，价码就不一样。界面上会实时显示“距暴击 N 次”。
[*][b]8种怪物特性[/b]：野兽、魔法、守护、不死、剑士、巨躯、暗杀、铠甲。暗杀在吃到暴击前会闪开所有普通攻击；铠甲得先打穿外壳才伤得到血；巨躯每挨五下就咆哮还击……每个章节的解法都不一样。
[*][b]三个技能[/b]：强击、铁壁、吸血，每层各能用一次，用在哪一场由你决定。显伤不把技能算进去，用得好，就能比显伤更省血。
[*][b]不用干等[/b]：战斗速度可在设置里选1倍、2倍或4倍，按住Space临时提到8倍；按Tab可以直接跳过战斗，结果和显伤完全一致（首领战不能跳过）。
[*][b]点击移动[/b]：点击地面即可移动，双击快速移动；WASD照常可用。
[*][b]钥匙与门[/b]：绿、黄、红三色门把每层分成几个区域；还有金库、备用钥匙、永久提升属性的符文（类似魔塔里的红蓝宝石），以及只能二选一的奖励。
[*][b]每层入口自动存档[/b]：进入每一层时自动存档，不能随时手动存档（没有SL）。死亡后回到本层入口；也可以在菜单的“检查点”里选最近10层中的任意一层重新开始。
[/list]

[h2]通关只是及格线[/h2]
[list]
[*][b]魔剑的账簿[/b]：每五层结算一次。魔剑拿你的“付出”（实际掉的血）去比“基准”（这几层的设计价码），评出★到★★★：★★表示比一般玩家付出更少，★★★表示前四分之一。结算会列出每一档星级的付出上限。基准只计你实际打过的战斗。“预言”（战前显伤之和）会并排列出，还会预告接下来五层的怪物特性。
[*][b]楼梯口的祭坛[/b]：付出一笔血量（价码按最大生命的百分比计），换取永久的攻击或防御（每次只能选一项）。每买一次价码就涨一截，剩下的血量不够就不卖。
[*][b]分数与排行榜[/b]：打到结局，账簿会把整局折成一个分数，越低越好。“普通”和“塔之法则”两种规则各有一张Steam排行榜，另有20个Steam成就。
[*][b]塔之法则[/b]：开新游戏时可选的规则。同样的地图，怪物下手更狠，每一瓶药水都算在预算里。第一次挑战，建议先选“普通”。
[/list]

[h2]故事[/h2]
佣兵达米安来到加布村，调查一座从天而降、倒插进大地的黑塔。在遗忘之森，他与会说话的魔剑“自我之剑”立下契约，押上了自己的灵魂与生命。
魔剑的独眼能看穿每一场战斗的价码，却唯独瞒下了一笔：契约者自己的价码。

[h2]100层，5个章节，3个结局[/h2]
苔藓地下墓穴、坍塌水道、灰烬熔炉、冰封深层、王座裂隙。每个章节都有自己的怪物特性组合，每20层一位章节首领。
魔剑会吃掉达米安所斩魔物的魔力。最后的选择有两个，结局却有三个。想看真正的结局，就得把魔剑喂饱：画面上会同时显示你的当前等级和每层的基准等级。

一次买断，没有DLC，没有内购。支持简体中文、英语、韩语、日语。

Silver 字体：Poppy Works（CC BY 4.0）
```

```text

```
