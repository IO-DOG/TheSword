# 스토어 문구 — 간체 중국어 (schinese)

붙일 곳: 스토어 페이지 관리 → **설명** 탭, 언어 = 简体中文. 규칙·태그·콘텐츠 설문 메모는 `ko.md` 와 같다.
魔塔 장르 리뷰의 84% 가 간체 중국어다(MASTER_PLAN §1). 그래서 이 페이지는 魔塔 팬의 말로 썼다.

| 魔塔 말 | 뜻 | 이 게임에서 |
|---|---|---|
| 显伤 | 몬스터 위에 받을 피해를 띄우는 것 | 맵 위 예측 숫자 (계약 뒤) |
| 临界 | 공격을 몇 올리면 맞는 횟수가 주는 문턱 | 도감의 "攻击 +k → 少挨一次" (ScriptData 265) |
| 楼传 | 층 이동 도구 | 20층 보스가 주는 传送石戒指 |

- 게임 안 이름·용어는 ScriptData 와 `Tools/story/story_cn.json` 에 맞췄다(自我之剑, 达米安, 加布村, 遗忘之森, 暴击, 怪物图鉴, 检查点…).
- 전통 魔塔 과 다른 점(체력 상한·넘침, 게이지 전투, 층 입구 저장)을 숨기지 않았다. 저장은 "어디서나" 가 아니라 **층 입구**다 —
  세이브 불만이 이 장르의 나쁜 리뷰에 2.2배 많이 나온다(§1). 기대를 먼저 맞춰 둔다.
- 중국어 편집자(W0) 검수 전 초안이다.

## 짧은 설명

```text
没有随机、不靠运气的魔塔RPG。会说话的魔剑用独眼看穿每场战斗要掉多少血——每只怪头顶都有精确显伤。每扇门、每把钥匙、每瓶药水，都是有价码的选择。规划100层的路线，把魔剑喂饱，最后决定由谁来付这笔账。
```

## 게임 정보 (About This Game)

```text
[h2]一座不靠运气的魔塔[/h2]
怪物不是敌人，是价码；生命不是命，是预算。塔里没有任何随机：怪物头顶的数字，就是这一战你要掉的血。你要决定的，只是先付哪一笔、按什么顺序付。

[h2]显伤、临界、楼传，一样不少[/h2]
[list]
[*][b]显伤[/b]：与魔剑立约之后，地图上每只怪物头顶都会显示“下一战会损失多少生命”。这个数字是把真实的战斗提前跑一遍算出来的，不用技能的话分毫不差。打不过的标红色X，打完能升级的标★。
[*][b]临界[/b]：怪物图鉴列出本层每种怪物的攻防血、剩余数量、下一战的价码、要挨几下，还有“攻击 +k → 少挨一次”。
[*][b]楼传[/b]：击败第20层首领后获得传送石戒指，去过的楼层都能直接传送回去。
[/list]

[h2]和传统魔塔不一样的地方[/h2]
[list]
[*][b]生命有上限[/b]：溢出的恢复会被浪费。什么时候踩药，本身就是计算。
[*][b]看得懂的槽式战斗[/b]：攻击槽、防御槽满了就自动出手。暴击不看概率，而是每隔固定次数必出，次数还会跨战斗累计——先打谁，价码就不一样。
[*][b]8种怪物特性[/b]：野兽、魔法、守护、不死、剑士、巨躯、暗杀、铠甲。吃到暴击之前闪避一切攻击的暗杀、得先打破外壳的铠甲、每挨五下就咆哮还击的巨躯……每个章节要找的解法都不同。
[*][b]三个技能[/b]：强击、铁壁、吸血，每场战斗各能用一次。显伤不计技能，用得好就能比预测打得更省。
[*][b]钥匙与门[/b]：绿、黄、红三色门把每层分成几个区域；还有金库、备用钥匙、永久提升的符文，以及只能二选一的奖励。
[*][b]每层入口自动存档[/b]：死亡后回到本层入口；也能从菜单回到最近10层中的任意一层重新开始。
[/list]

[h2]故事[/h2]
佣兵达米安来到加布村，调查一座从天而降、倒插进大地的黑塔。在遗忘之森，他与会说话的魔剑“自我之剑”立下契约，押上了自己的灵魂与生命。
魔剑的独眼能看穿每一场战斗的价码，却唯独藏起了一个：契约者自己的价码。

[h2]100层，5个章节，3个结局[/h2]
苔藓地下墓穴、坍塌水道、灰烬熔炉、冰封深层、王座裂隙。每个章节都有自己的怪物特性组合，每20层一位章节首领。
魔剑会吃掉达米安所斩魔物的魔力。最后的选择有两个，结局却有三个。只有把魔剑喂饱的人，才能看到真正的结局。

一次买断，没有DLC，没有内购。
```
