# 스토어 문구 — 번체 중국어 (tchinese) — 번체가 들어간 뒤의 빌드용 초안

붙일 곳: 스토어 페이지 관리 → **설명** 탭, 언어 = 繁體中文. 규칙·태그·콘텐츠 설문 메모·줄마다의 근거는 `ko.md` 와 같다.

**이 파일은 미래 빌드용이다. 지금 게임에는 번체가 없다.** 게임 안 중국어는 간체 하나이고, 번체는 LOC1(W2)에서 들어온다(README D3: 데모에 넣을지는 번역가에 달렸다).

- Steamworks 의 지원 언어 표에서 번체(Traditional Chinese)는 **게임에 번체가 들어간 뒤에만** 체크한다. 이 파일의 어떤 줄도 번체를 지원한다고 말하지 않는다 — 본문 끝의 "지원 언어" 문장도 일부러 뺐다.
- 붙여 넣는 글의 **첫 줄**("本遊戲的中文介面為簡體中文，未提供繁體中文。下文引用的遊戲畫面文字照錄簡體原文。")은 번체가 들어가기 전에 이 페이지를 올릴 때의 사실이다 — 지금은 이 줄이 맞다. 사실만 적고 날짜는 약속하지 않는다("目前" 같은 말을 쓰지 않는다).
  이 줄과 어긋나지 않게, 본문이 따옴표(「」)로 인용한 **화면 글자는 지금 게임에 뜨는 간체 그대로** 적었다(「战斗预测」·「距暴击 N 次」·「检查点」·「预言」·「付出」·「基准」·「塔之法则」…).
- 번체가 게임에 들어가면: 첫 줄을 빼고, 따옴표 속 화면 글자를 LOC1 의 번체 번역으로 바꾸고, AI 사용 공개의 번역 괄호를 "英文、日文、簡體中文、繁體中文" 으로 바꾸고, 본문 끝에 지원 언어 문장을 더한다.
- 본문의 "Steam排行榜"·"20個Steam成就" 는 Steamworks 에 그 순위표·업적을 만들어 Publish 한 뒤에만 붙인다(README 5절). 시스템 요구 사항 표에는 處理器·記憶體 행이 없다 —
  측정값이 나오면 오케스트레이터가 채운다(`ko.md` 머리말). 본문 맨 끝 줄은 글꼴 Silver 의 CC BY 4.0 표기다.
- 간체 초안(`zh-CN.md`)을 옮겼다. 글자만 바꾸지 않고 대만 쪽 말로 고쳤다(存檔, 記憶體, 顯示卡, 滑鼠, 支援, 設定, 選單, 即時, 挑戰, 事先…).
  게임 안 이름(自我之劍, 達米安, 加布村, 遺忘之森, 暴擊, 怪物圖鑑, 魔劍的帳簿, 祭壇, 塔之法則…)은 따옴표 밖에서는 번체로 적었고 LOC1 의 번체 번역이 나오면 그쪽에 맞춘다. 원어민 검수 전 초안이다.
- 2026-11-03 갱신: `main` `970333f3`(Wave 3 포함) 빌드 기준. 간체 판과 같은 사실을 같은 순서로 말한다.

## 게임 정보 (About This Game)

```text
本遊戲的中文介面為簡體中文，未提供繁體中文。下文引用的遊戲畫面文字照錄簡體原文。

[h2]一座不靠運氣的魔塔[/h2]
怪物不是敵人，是價碼；血量不是命，是預算。塔裡沒有任何隨機：怪物頭上的數字，就是這一戰你要掉的血。你要決定的，只是付哪幾筆、按什麼順序付。

[h2]顯傷、臨界、樓傳，一樣不少[/h2]
[list]
[*][b]顯傷[/b]（遊戲內叫「战斗预测」）：與魔劍立約之後，地圖上每隻怪物頭上都會顯示「下一戰會損失多少生命」。這個數字是把真實的戰鬥提前跑一遍算出來的，不用技能的話分毫不差。打不過的標紅色X，打完能升級的標★。
[*][b]臨界[/b]：打開怪物圖鑑（就是魔塔老玩家熟悉的「怪物手冊」），本層每種怪的攻防血、剩餘數量、下一戰的價碼、要挨幾下一目了然，臨界直接寫明——「攻击 +k → 少挨一次」。把滑鼠移到攻擊／防禦符文上，還會事先告訴你撿起它之後，哪些怪的顯傷會從多少降到多少。
[*][b]樓傳[/b]：擊敗第20層頭目後獲得傳送石戒指，去過的樓層都能直接傳送回去。
[/list]

[h2]和傳統魔塔不一樣的地方[/h2]
[list]
[*][b]生命有上限[/b]：藥水（就是魔塔裡的血瓶）回復超出上限的部分會白白浪費，什麼時候喝，本身就是一道計算題。
[*][b]看得懂的槽式戰鬥[/b]：攻擊槽、防禦槽滿了就自動出手。暴擊不看機率，而是每隔固定次數必出，次數會帶到下一場戰鬥——先打誰，價碼就不一樣。畫面上會即時顯示「距暴击 N 次」。
[*][b]8種怪物特性[/b]：野獸、魔法、守護、不死、劍士、巨軀、暗殺、鎧甲。暗殺在吃到暴擊前會閃開所有普通攻擊；鎧甲得先打穿外殼才傷得到血；巨軀每挨五下就咆哮還擊……每個章節的解法都不一樣。
[*][b]三個技能[/b]：強擊、鐵壁、吸血，每層各能用一次，用在哪一場由你決定。顯傷不把技能算進去，用得好，就能比顯傷更省血。
[*][b]不用乾等[/b]：戰鬥速度可在設定裡選1倍、2倍或4倍，按住Space暫時提到8倍；按Tab可以直接跳過戰鬥，結果和顯傷完全一致（頭目戰不能跳過）。
[*][b]點擊移動[/b]：點擊地面即可移動，雙擊快速移動；WASD照常可用。
[*][b]鑰匙與門[/b]：綠、黃、紅三色門把每層分成幾個區域；還有金庫、備用鑰匙、永久提升屬性的符文（類似魔塔裡的紅藍寶石），以及只能二選一的獎勵。
[*][b]每層入口自動存檔[/b]：進入每一層時自動存檔，不能隨時手動存檔（沒有SL）。死亡後回到本層入口；也可以在選單的「检查点」裡選最近10層中的任意一層重新開始。
[/list]

[h2]通關只是及格線[/h2]
[list]
[*][b]魔劍的帳簿[/b]：每五層結算一次。魔劍拿你的「付出」（實際掉的血）去比「基准」（這幾層的設計價碼），評出★到★★★：★★表示比一般玩家付出更少，★★★表示前四分之一。結算會列出每一檔星級的付出上限。基準只計你實際打過的戰鬥。「预言」（戰前顯傷之和）會並排列出，還會預告接下來五層的怪物特性。
[*][b]樓梯口的祭壇[/b]：付出一筆血量（價碼按最大生命的百分比計），換取永久的攻擊或防禦（每次只能選一項）。每買一次價碼就漲一截，剩下的血量不夠就不賣。
[*][b]分數與排行榜[/b]：打到結局，帳簿會把整局折成一個分數，越低越好。「普通」和「塔之法则」兩種規則各有一張Steam排行榜，另有20個Steam成就。
[*][b]塔之法則[/b]：開新遊戲時可選的規則。同樣的地圖，怪物下手更狠，每一瓶藥水都算在預算裡。第一次挑戰，建議先選「普通」。
[/list]

[h2]故事[/h2]
傭兵達米安來到加布村，調查一座從天而降、倒插進大地的黑塔。在遺忘之森，他與會說話的魔劍「自我之劍」立下契約，押上了自己的靈魂與生命。
魔劍的獨眼能看穿每一場戰鬥的價碼，卻唯獨瞞下了一筆：契約者自己的價碼。

[h2]100層，5個章節，3個結局[/h2]
苔蘚地下墓穴、坍塌水道、灰燼熔爐、冰封深層、王座裂隙。每個章節都有自己的怪物特性組合，每20層一位章節頭目。
魔劍會吃掉達米安所斬魔物的魔力。最後的選擇有兩個，結局卻有三個。想看真正的結局，就得把魔劍餵飽：畫面上會同時顯示你目前的等級和每層的基準等級。

一次買斷，沒有DLC，沒有內購。

Silver 字型：Poppy Works（CC BY 4.0）
```
