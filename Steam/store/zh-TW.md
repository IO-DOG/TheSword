# 스토어 문구 — 번체 중국어 (tchinese)

붙일 곳: 스토어 페이지 관리 → **설명** 탭, 언어 = 繁體中文. 규칙·태그·콘텐츠 설문 메모는 `ko.md` 와 같다.

- **게임 안에는 아직 번체가 없다.** 지금 게임의 중국어는 간체 하나이고, 번체는 LOC1(W2)에서 들어온다(D3: 데모에 넣을지는 번역가에 달렸다).
  Steamworks 의 지원 언어 표에서 번체는 **게임에 들어간 뒤에만** 체크한다.
- 번체가 들어가기 전에 이 페이지를 올리면 "게임 정보" 끝에 다음 한 줄을 붙인다(사실만 적고 날짜는 약속하지 않는다):
  `遊戲內文字目前為簡體中文。`
- 간체 초안(`zh-CN.md`)을 옮겼다. 글자만 바꾸지 않고 대만 쪽 말로 고쳤다(存檔, 記憶體, 顯示卡, 滑鼠, 支援…).
  게임 안 이름(自我之劍, 達米安, 加布村, 遺忘之森, 暴擊, 怪物圖鑑…)은 LOC1 의 번체 번역이 나오면 그쪽에 맞춘다. 원어민 검수 전 초안이다.

## 짧은 설명

```text
沒有隨機、不靠運氣的魔塔RPG。會說話的魔劍用獨眼看穿每場戰鬥要掉多少血——每隻怪頭上都有精確顯傷。每扇門、每把鑰匙、每瓶藥水，都是有價碼的選擇。規劃100層的路線，把魔劍餵飽，最後決定由誰來付這筆帳。
```

## 게임 정보 (About This Game)

```text
[h2]一座不靠運氣的魔塔[/h2]
怪物不是敵人，是價碼；生命不是命，是預算。塔裡沒有任何隨機：怪物頭上的數字，就是這一戰你要掉的血。你要決定的，只是先付哪一筆、按什麼順序付。

[h2]顯傷、臨界、樓傳，一樣不少[/h2]
[list]
[*][b]顯傷[/b]：與魔劍立約之後，地圖上每隻怪物頭上都會顯示「下一戰會損失多少生命」。這個數字是把真實的戰鬥提前跑一遍算出來的，不用技能的話分毫不差。打不過的標紅色X，打完能升級的標★。
[*][b]臨界[/b]：怪物圖鑑列出本層每種怪物的攻防血、剩餘數量、下一戰的價碼、要挨幾下，還有「攻擊 +k → 少挨一次」。
[*][b]樓傳[/b]：擊敗第20層首領後獲得傳送石戒指，去過的樓層都能直接傳送回去。
[/list]

[h2]和傳統魔塔不一樣的地方[/h2]
[list]
[*][b]生命有上限[/b]：溢出的恢復會被浪費。什麼時候踩藥，本身就是計算。
[*][b]看得懂的槽式戰鬥[/b]：攻擊槽、防禦槽滿了就自動出手。暴擊不看機率，而是每隔固定次數必出，次數還會跨戰鬥累計——先打誰，價碼就不一樣。
[*][b]8種怪物特性[/b]：野獸、魔法、守護、不死、劍士、巨軀、暗殺、鎧甲。吃到暴擊之前閃避一切攻擊的暗殺、得先打破外殼的鎧甲、每挨五下就咆哮還擊的巨軀……每個章節要找的解法都不同。
[*][b]三個技能[/b]：強擊、鐵壁、吸血，每場戰鬥各能用一次。顯傷不計技能，用得好就能比預測打得更省。
[*][b]鑰匙與門[/b]：綠、黃、紅三色門把每層分成幾個區域；還有金庫、備用鑰匙、永久提升的符文，以及只能二選一的獎勵。
[*][b]每層入口自動存檔[/b]：死亡後回到本層入口；也能從選單回到最近10層中的任意一層重新開始。
[/list]

[h2]故事[/h2]
傭兵達米安來到加布村，調查一座從天而降、倒插進大地的黑塔。在遺忘之森，他與會說話的魔劍「自我之劍」立下契約，押上了自己的靈魂與生命。
魔劍的獨眼能看穿每一場戰鬥的價碼，卻唯獨藏起了一個：契約者自己的價碼。

[h2]100層，5個章節，3個結局[/h2]
苔蘚地下墓穴、坍塌水道、灰燼熔爐、冰封深層、王座裂隙。每個章節都有自己的怪物特性組合，每20層一位章節首領。
魔劍會吃掉達米安所斬魔物的魔力。最後的選擇有兩個，結局卻有三個。只有把魔劍餵飽的人，才能看到真正的結局。

一次買斷，沒有DLC，沒有內購。
```
