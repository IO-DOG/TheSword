# ChapterKit — 챕터별 임시 복셀 그림

5~100층의 다섯 챕터가 **색 필터가 아니라 다섯 곳**으로 보이게 하는 임시 그림이다. 게임의 복셀 화풍 그대로
(복셀 0.1, MagicaVoxel 식 OBJ + 256x1 팔레트) 벽 4종 x 5챕터와 소품 22개를 `Tools/voxel_kit.py` 가 절차적으로 굽는다.
기획은 `Documents/TheSword_Meshy_Prompts.md` 의 이름표·분위기·지킬 것을 따른다. Meshy 그림이 들어오면 같은 이름끼리 Meshy 가 이긴다.

**손으로 고치지 않는다** — 파일은 다시 구우면 덮인다. 고칠 것은 `Tools/voxel_kit.py` 의 챕터 함수(`_chapterN`)에서 고치고 다시 굽는다.

```bash
python Tools/voxel_kit.py build                 # 다섯 챕터 -> 이 폴더 + 미리보기·대조표(임시 폴더/voxel_kit_preview)
python Tools/voxel_kit.py build --only 2 --preview D:/tmp/kit   # 한 챕터만, 미리보기 위치 지정
python Tools/voxel_kit.py check                 # 굽지 않고 경계·자리 상자·삼각형 예산·OBJ 왕복만 잰다
python Tools/voxel_kit.py inspect Assets/Resources/Tilemap_C0_W02.obj   # 기존 MagicaVoxel OBJ 를 읽어 그려 본다
```

numpy·Pillow 만 쓰고, 씨앗이 고정이라 같은 코드면 같은 파일이 나온다(바이트 단위).

## 들여오는 법

1. Unity 메뉴 **TheSword → Import Meshy Art** — `MeshyArtImport` 가 이 폴더(`ChapterKit/`)를 먼저, `Art/Meshy/` 를 나중에 담는다.
   같은 이름이 둘 다 있으면 Meshy 그림이 이긴다. 결과는 `Art/Built/{이름}.prefab` + 어드레서블 "PreLoad".
2. 소품(`Prop_*`)이 처음 들어갔으면 **TheSword → Build Map Decorations**. 벽은 `MapBuilder` 가 런타임에 고른다
   (`Wall_C{ch}_{변형}` → 없으면 `Wall_C{ch}_Base` → 없으면 옛 `Tilemap_C00_W0x`).
3. 새 벽에는 챕터 틴트를 곱하지 않는다(`MapBuilder` 가 `Color.white` 로 놓는다) — 챕터 색은 팔레트에 들어 있다.

도구가 복셀 그림을 재는 법: 축척은 옛 장식과 같은 0.1 그대로 두고 자리만 붙인다. 아래 상자를 넘으면 그만큼 줄여서
복셀 크기가 벽과 달라지므로, 생성기가 굽기 전에 상자를 검사한다(`check_fit`).

| 자리 | 상자(복셀) | 붙는 점 | 이 키트 |
|---|---|---|---|
| 벽 `Wall_C?_*` | 32 x 45 x 32 | 바닥 가운데 → 옛 벽 바닥면(y 0.2) | x/z 정확히 -1.6..1.6(대칭), y 2.0..≤5.3 |

## 좌표와 생김새 규칙

- 복셀 하나 = 모델 0.1 = 월드 0.01(축척 0.1). 벽 몸통은 W02 와 같은 x/z -1.5..1.5, y 2.0..5.0.
- **윗면 덮개는 발자국 밖으로 한 칸(0.1) 나온다** → 이웃 벽 덮개와 맞닿아 줄지어 선 벽의 윗면이 한 장으로 이어진다(몸통 사이 0.2 틈은
  덮개 아래 그림자 줄눈으로만 보인다). 윗면 무늬는 주기 32 잡음이라 이음매가 없고, 변형(A/B/C)은 가장자리 띠를 기본형과 같게 두고
  안쪽만 바꿔 기본형 옆에 서도 이어진다(무너진 귀퉁이처럼 일부러 끊는 곳은 빼고).
- 위로는 0.3(y 5.3)까지만 — 그 위는 뒤 칸의 그림을 가린다. 가시·굴뚝·떠오른 조각처럼 높아야 하는 것은 그 변형의 윗면을 낮추고 그 높이를 채운다.
- 카메라는 남쪽에서 내려다본다(대조표는 스크린샷에서 잰 60°, 정사영). 그래서 윗면과 **남쪽(-z) 면**에만 줄눈 홈·벽감·창살·배수구·화살 구멍·흘러내린 슬래그를 둔다.
  나머지 세 면은 칠만 하고, 아랫면(-y)은 아무 카메라·해도 보지 못해 아예 내보내지 않는다(삼각형 약 10% 절약).
- OBJ 는 MagicaVoxel 처럼 삼각형·면마다 법선 하나·u = (색 번호 - 1 + 0.5)/256. Unity 가 OBJ 의 x 를 뒤집으므로 생성기는 Unity 공간으로 짓고 쓸 때만 x 를 뒤집는다.
- 재질 이름은 파일 이름과 같다(모두 `palette` 이면 재질을 밖으로 빼는 설정에서 서로 덮어쓴다).
- `*_Emit.png` = 같은 팔레트에서 빛나는 칸(불꽃·숯·유리·빛 균열·수정)만 남기고 나머지는 검정. 지금 `MeshyArtImport` 는 쓰지 않는다 —
  `_EmissionMap` 으로 걸면 그 칸만 빛난다. 안 걸어도 그 색들은 밝게 칠해 두어 빛만 받으면 읽힌다.
- 글자·비문·낙서·눈은 없다. 높이 계단이 있는 잔무늬는 낮은 해 아래 그림자 선이 글자처럼 읽혀서 윗면(재·눈·덮개)은 평평하게 두고 색으로만 무늬를 냈다.
