# Tripo 결과물 넣는 곳

Tripo 에서 뽑은 모델(GLB)을 이름 규칙대로(`Wall_C1_Base.glb` 처럼) 이 폴더에 넣고 Unity 메뉴
**TheSword → Import Meshy Art** 를 누른다(이름은 Meshy 지만 이 폴더도 읽는다). 소품을 처음 넣었으면
**TheSword → Build Map Decorations** 도.

설정·프롬프트·확인할 것은 `Documents/TheSword_Tripo_Prompts.md`. 같은 이름이 여러 곳에 있으면
Tripo(이 폴더) > `../Meshy/` > `../ChapterKit/`(임시 복셀 그림) 순으로 이긴다.
