# Tripo 벽 프롬프트 20개 — 한 번에 하나씩

**파일 전체를 붙이지 않는다.** 벽 하나 = Tripo 생성 한 번. 아래 회색 줄 **하나**만 복사해 Tripo 프롬프트 칸에 넣는다.

순서: ① 회색 줄 복사 → ② Tripo 에 붙여 생성 → ③ GLB 로 내려받기 → ④ 파일 이름을 제목의 이름(예: `Wall_C0_Base.glb`)으로 바꾸기 → ⑤ `Assets/@Resources/Art/Tripo/` 에 넣기 → 다음 번호

## 매번 같은 설정

- 모델: P 시리즈(저폴리) — 없으면 Smart Low Poly
- 면 수(face limit): 2800
- Quad 끔 · PBR 끔 · 내보내기 GLB
- 네거티브 프롬프트 칸(있으면, 매번 같은 것):

```
realistic, photorealistic, high detail, smooth organic, text, letters, logo, ground plane, base platform, pedestal, baked shadows, multiple objects, grass block, grass, wooden planks, dirt, hollow, open top, container
```

고를 때: 정육면체에 가까운 것, 텍스처에 그림자가 안 구워진 것. ★ 표시는 장식이 미리보기 **정면**에 와야 한다.
