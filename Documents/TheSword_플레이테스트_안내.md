# TheSword 체험판 플레이테스트 안내

지인 3~5명에게 체험판(1~20층)을 해 보게 하고 반응을 모으는 데 쓴다. 봇과 시뮬레이션은 "판단이 결과를 바꾼다" 까지만 보여 준다 —
**그 판단이 즐거운지**, 초반이 늘어지지 않는지, 규칙이 읽히는지는 사람만 알려 준다(2026-11-26).

## 1. 보낼 것

- `Build/Playtest/TheSword_Demo_<날짜>.zip` — 체험판 빌드 + 이 문서의 "2. 테스터에게" 부분(`테스터_안내.txt`). Steam 없이 켜진다.
- 저장소에 올리지 않는다(`Build/` 는 커밋 안 함). 파일 공유(드라이브 등)로 보낸다.
- 묶기: 체험판을 다시 구운 뒤 `python Tools/playtest_zip.py`(오늘 날짜 zip). 안내 글은 아래 2절 블록 그대로 들어간다 — 2절을 고치면 다시 묶고,
  보내기 전에 `python Tools/playtest_zip.py --check <zip>` 이 "같다" 인지 본다.

## 2. 테스터에게 (zip 안의 `테스터_안내.txt` 와 같은 글)

```
TheSword 체험판을 해 주셔서 고맙습니다.

[켜기]
- zip 은 바탕화면이나 다운로드 폴더처럼 얕은 곳에 풉니다(폴더가 너무 깊으면 Windows 경로 길이 제한에 걸려 파일 하나가 안 풀립니다).
- 푼 폴더에서 TheSword.exe 를 실행합니다. Steam 은 필요 없습니다.
- "Windows의 PC 보호" 창이 뜨면 '추가 정보' → '실행' 을 누릅니다(서명하지 않은 개발판이라 뜹니다).
- 패드(엑스박스 패드)도 됩니다. 키보드: WASD 이동, M 몬스터 도감, Esc 메뉴.

[부탁]
- 처음 30분은 아무 설명 없이, 게임이 알려 주는 것만 보고 해 주세요. 그게 가장 중요한 자료입니다.
- 막히거나, 헷갈리거나, 지루하거나, 짜증 난 순간이 있으면 층 번호와 함께 한 줄만 적어 주세요.
- 체험판은 21층에 들어서면 끝납니다. 다 못 해도 괜찮습니다. 그만둔 층과 이유를 알려 주세요.
- 할 수 있으면 화면 녹화(예: OBS, Xbox Game Bar Win+Alt+R)를 해 주시면 큰 도움이 됩니다.

[끝나고 — 설문]
아래 물음에 답해 주세요(점수는 1 = 전혀 아니다, 5 = 매우 그렇다). 짧게 써도 됩니다.
 1. 몇 층까지 했나요? 걸린 시간은?
 2. 몬스터 머리 위 숫자(잃을 체력)가 무슨 뜻인지 언제 알았나요? (바로 / 몇 층 뒤 / 끝까지 몰랐다)
 3. "어느 몬스터를 먼저 잡을까·어느 문을 열까" 를 고민한 적이 있나요? 그 고민이 재밌었나요? (1~5)
 4. 전투를 지켜보는 시간이 길게 느껴졌나요? 배속·건너뛰기(Tab)를 썼나요?
 5. 도감(M)을 열어 봤나요? 도움이 됐나요?
 6. 가장 재밌었던 순간 하나
 7. 그만두고 싶었던 순간 하나(층 번호)
 8. 이야기·대사는 어땠나요? 너무 길거나 짧았던 곳
 9. 그림·소리에서 거슬린 것
10. 정식판(100층)이 나오면 사거나 찜하겠어요? (1~5) 왜?
11. 비슷하다고 느낀 게임이 있나요?

[문제가 생기면]
- 게임이 멈추거나 꺼지면, 아래 파일을 보내 주세요:
  %USERPROFILE%\AppData\LocalLow\CozyByte\TheSword\Player.log
- 처음부터 다시 하려면 타이틀의 '새 게임' 을 누르면 됩니다.
```

## 4. 오너가 옆에서 볼 때 (보이는 대로 적기)

말을 끊지 않고 지켜보다가 아래가 언제 일어나는지만 적는다.

- 처음으로 머리 위 숫자를 보고 몬스터를 고른 층, 처음으로 빨간 X 를 보고 피한 층
- 3층 마검 계약 대사에서 Tab(건너뛰기)을 누르는지, 몇 초 읽는지
- 열쇠가 모자라 문 앞에서 멈칫한 곳, 되돌아간 곳
- 5·10·15층 끝 제단(체력으로 공격/방어 사기)에서 사는지 지나가는지, 이유
- 스킬(1/2/3) 을 처음 쓴 층
- 휴대폰을 보거나 한숨 쉬는 등 지루해 보인 층
- 20층 보스에서 몇 번 죽었는지
- (본편을 맡길 사람이 있으면) **41~60층에서 지루해하는지** — 시뮬레이션으로는 챕터 1·2(21~60층)의 몹 한 판이 최대 체력의 2% 남짓이라
  싸움이 싱겁고 물약 회복의 절반 넘게가 넘쳐 버려진다(재미 검증 v2 6.5). 사람이 같은 말을 하면 챕터 1·2 몹 손실을 올린다(오너 결정).

## 5. 모은 뒤

- 같은 말이 둘 이상에게서 나온 것부터 본다. 한 사람만 말한 것은 메모만.
- 고칠 것(글·안내·속도)은 회차 백로그로, 디자인 결정(곡·그림·규칙)은 오너가 정한다.
